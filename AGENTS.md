# BinaryCod — Reglas del Proyecto

## Contexto del proyecto

BinaryCod es una aplicación web educativa orientada a Comunicación de Datos e Ingeniería.

La aplicación permite:

- codificación de mensajes
- decodificación
- compresión binaria
- visualización de árboles
- análisis de frecuencias
- comparación entre Huffman y Shannon-Fano
- visualización de métricas y gráficos
- compresión bitmap blanco y negro

El proyecto debe sentirse como un software web moderno, tecnológico y profesional.
